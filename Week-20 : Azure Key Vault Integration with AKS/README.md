# Week 20 of Azure Series 🚀

## Azure Key Vault Integration with AKS 🔐

Managing secrets securely is a crucial part of cloud-native applications.
This week, we explore **Azure Key Vault (AKV)** integration with **Azure Kubernetes Service (AKS)** using the **Secrets Store CSI Driver**.

---

## 🔹 Why Use Azure Key Vault?

* **Centralized secrets management** 🗄️
* **Secure storage** for keys, certificates, and passwords 🔑
* **Role-Based Access Control (RBAC)** for granular security 🎯
* **Compliance** with password rotation policies 🔄

---

## 🔹 What’s Covered?

* Setting up an **AKS cluster** with Azure Key Vault support ⚙️
* Configuring a **managed identity** for authentication 🔄
* Deploying a **pod** that accesses secrets stored in Azure Key Vault 🛠️
* Implementing the **Secret Store CSI Driver** for seamless secret retrieval 🔍
* **Best practices** and troubleshooting for smooth integration ✅
